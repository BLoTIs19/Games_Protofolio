About this shelf

    
This page is a template: swap the copy, the palette, and every entry in projects.js for your own. The grid scales to any number of cartridges — three or three hundred — because it's built from one JavaScript array, not hand-written HTML per project.

    
Anyone can browse. Only the signed-in admin can add new cartridges to the shelf.

  






  
Built with plain HTML, CSS and JS — no framework, no build step.

Add a project to the shelf

    
This site is a static page — perfect for GitHub Pages, but it has no server to store uploads permanently. Submitting this adds the project to the shelf right now (saved in this browser), and gives you a ready-to-paste code block for projects.js so it shows up for every visitor once you publish it.
